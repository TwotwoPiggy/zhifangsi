# zhifangsi-check: 关防守则静态合规巡检

当用户输入 `/zhifangsi-check`、`/zhifangsi-lint`，或在提交代码、重构前核验分层守则时执行。

## 执行准则与步骤

1. **调用巡检引擎**：
   - 优先调用 MCP 军机工具 `zhifangsi_check_invariants`（参数：`{ "target_dir": "<目标目录>" }`）；
   - 若在非 MCP 交互环境中，直接在终端执行全局命令：
     ```bash
     zhifangsi check "<目标目录>"
     ```

2. **违规分类与排查处理**：
   - **错误级别 (`[错误 ERROR]`)**：属于不可逾越的硬性架构红线（如 UI 直接调用底层 DB、底层反向依赖上层等）。必须直接指出代码行号、违规文件与越权依赖目标；
   - **告警级别 (`[告警 WARN]`)**：属于建议关注的软性约束。

3. **提供修复建议**：
   - 针对发现的每处违规，给出针对性重构建议（如通过依赖注入解耦、引入 Store/Service 中介层等）。
