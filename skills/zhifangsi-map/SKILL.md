# zhifangsi-map: 测绘战略全景舆图

当用户输入 `/zhifangsi-map` 或需要全面摸底代码库架构中枢、核心关隘与依赖拓扑时执行。

## 执行准则与步骤

1. **确定目标代码库**：
   - 优先使用用户指定的路径；若未指定，则默认为当前工作区根目录。

2. **调用测绘引擎**：
   - 优先调用 MCP 军机工具 `zhifangsi_map`（参数：`{ "target_dir": "<目标目录>" }`）；
   - 若 MCP 环境未就绪，直接在终端执行全局命令：
     ```bash
     zhifangsi map "<目标目录>"
     ```

3. **解读与结构化输出**：
   - **核心枢纽 (Top Architectural Hubs)**：列出基于 PageRank 算出的核心枢纽文件，标注入度、出度与耦合权重；
   - **注册模块 (wiki/modules/)**：梳理目前已建立独立认知档案的模块；
   - **关防守则 (wiki/invariants/)**：汇报当前生效的不变量守则及合规健康状况；
   - **重构预警**：对入度极高且出度庞大的文件，主动提示其为高风险咽喉要道，建议优先做好解耦。
