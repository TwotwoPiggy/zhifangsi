# zhifangsi-map: 测绘并生成战略全景舆图

当用户输入 `/zhifangsi-map`、要求生成代码库舆图或分析架构核心枢纽时执行。

## 执行准则与步骤

1. **确定目标代码库与输出路径**：
   - 目标路径：优先使用用户指定的路径；未指定时默认为当前工作区根目录；
   - 落地文件：**必须生成并持久化写入 Markdown 文件**，默认保存至 `<目标目录>/CODEBASE_MAP.md`。

2. **调用测绘引擎并落地文件**：
   - **MCP 方式（优先）**：
     调用 MCP 军机工具 `zhifangsi_map`，传入参数：
     ```json
     {
       "target_dir": "<目标目录>",
       "output_file": "CODEBASE_MAP.md"
     }
     ```
   - **CLI 方式（备用）**：
     直接在终端执行全局命令（支持指定输出文件）：
     ```bash
     zhifangsi map "<目标目录>" "<目标目录>/CODEBASE_MAP.md"
     ```
   - **Agent 文件生成兜底**：
     若通过工具获取到了舆图内容，务必使用文件写入工具将完整的全景舆图持久化保存至 `<目标目录>/CODEBASE_MAP.md`，绝不能仅在对话中分析而不落盘文件。

3. **解读与结构化汇报**：
   - 明确告知用户舆图文件已落盘生成，并附上文件链接：`[CODEBASE_MAP.md](...)`；
   - **核心枢纽 (Top Architectural Hubs)**：列出基于 PageRank 算出的核心枢纽文件，标注入度、出度与耦合权重；
   - **注册模块 (wiki/modules/)**：梳理目前已建立独立认知档案的模块；
   - **关防守则 (wiki/invariants/)**：汇报当前生效的不变量守则及合规健康状况；
   - **重构与防腐建议**：对入度极高且出度庞大的文件，主动提示其为高风险咽喉要道，建议优先做好解耦。
